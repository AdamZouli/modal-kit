# Accessibility matrix

Phase 1 modal surface checks. Update when adapters change.

| Behavior | Core | React | Vue | Web Components |
| --- | --- | --- | --- | --- |
| Focus trap | unit | ConfirmModal / Modal | ConfirmModal / Modal | confirm / dialog |
| ESC closes top only | unit | integration | manual | host stack |
| Overlay closes top only | unit | ConfirmModal | ConfirmModal | confirm |
| Focus restore | unit | via core | via core | via core |
| Scroll lock | unit | via core | via core | via core |
| aria-labelledby | controller | ConfirmModal | ConfirmModal | confirm |
| Buried / inert non-top | sync attrs | layer CSS | layer CSS | layer CSS |
| Reduced motion | CSS | exit delay 0 | exit delay 0 | exit delay 0 |
| Async confirm + retry | n/a | ConfirmModal | ConfirmModal | confirm event promise |

Keyboard-only and screen-reader passes should be re-run before each minor release using the confirm demo and theme gallery.
